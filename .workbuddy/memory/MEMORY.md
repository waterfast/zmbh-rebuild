# 项目长期约定（zmbh-rebuild）

## UI 组件职责边界
- 展示型组件（如 `InventoryItemDetails`）只负责「渲染什么 + 报告自身尺寸」，不保存定位策略（锚点、跟随鼠标的开关、夹取常量等一律不进组件）。
- 组件通过**信号**（例如 `panel_resized(size)`）向外报告尺寸变化，由**调用方**决定放在哪里、怎么夹进视口。
- 定位不要用「延迟一帧算一次」的写法：内容尺寸的布局要到一两帧后才稳定，容易读到场景默认值导致错误钳制。用尺寸变化信号驱动，或每帧重算。

## 其他
- 老项目 `oldproject/` 仅供行为参考，不模仿写法；商店/背包等悬停详情的老逻辑见 `oldproject/.../Script/BackPack/Box_1.gd`（商店走 `is_in_shop` 分支，面板贴鼠标 +25,-20）。
- 测试脚本（extends SceneTree）内部若发生脚本错误，`quit()` 不会执行，进程会挂起而不是报错——排查"卡死"时先怀疑越界/空引用。
